# Commonplace

A small public shelf of links worth going back to: https://funferall.github.io/links/

The store is `links.js` — one array, one entry per link:

```js
{ id:'librepaper', url:'https://librepaper.org/', title:'LibrePaper',
  domain:'librepaper.org', note:'one or two lines on why it is here',
  tags:['writing','latex'], added:'2026-10-31' }
```

Ask Thoth in Discord ("save this link") and it gets committed here. The page sorts newest first and filters by tag and free text.
